## 先记住这三句话

1. 资料是**输入**，笔记是**加工**，代码是**输出**；只有输入没有输出 = 没学。
2. 侯捷问的是「为什么这么设计」，不是「怎么用」；回答不了「为什么」就是没懂。
3. 验收标准不是「我看完了」，而是「我能给别人讲清楚，且编译器同意我」。
